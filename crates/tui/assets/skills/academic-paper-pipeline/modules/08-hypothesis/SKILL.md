# 科学假设生成

从观察到可检验假设的 8 步系统流程。

## 工作流

### 1. 理解现象

- 确定需要解释的核心观察或模式
- 定义现象范围和边界
- 明确已知和不确定的内容

### 2. 文献检索

- PubMed（生物医学）/ Semantic Scholar（通用）/ arXiv（ML/CS）
- 寻找已有理论、机制或框架
- 识别当前理解中的空白

### 3. 综合现有证据

- 总结当前对该现象的理解
- 确定可能适用的已有机制或理论
- 指出矛盾证据或替代观点

### 4. 生成竞争性假设

开发 3-5 个可区分、可检验的假设。每个假设应包含：
- **机制解释**：说明 HOW 和 WHY（不是描述性）
- **支持证据**：2-3 个关键文献引用
- **核心假设**：1-2 个关键假设前提

### 5. 评估假设质量

| 标准 | 说明 |
|------|------|
| **可检验性** | 能否通过实验检验？ |
| **可证伪性** | 什么观察会推翻它？ |
| **简洁性** | 是否是最简单的解释？ |
| **解释力** | 能解释多少现象？ |
| **一致性** | 是否与已有原理一致？ |
| **新颖性** | 是否提供新的见解？ |

### 6. 设计实验方案

每个可行假设都应配套实验方案：
- 测量什么、如何测量
- 需要的对照和比较组
- 样本量和统计方法
- 潜在的混杂因素及处理方式

### 7. 制定可检验预测

将假设转化为具体、可量化的预测：
- 如果假设正确，应观察到什么？
- 预期效应方向和大小的量化
- 哪些预测可以区分竞争性假设
- 什么会证伪该假设

### 8. 生成结构化输出

输出为 LaTeX 文档，结构如下：
- **Executive Summary**（0.5-1 页）
- **Competing Hypotheses**（2-2.5 页，每个假设用彩色框）
- **Testable Predictions**（0.5-1 页）
- **Appendices**：详细文献综述、完整实验方案、质量评估

总引用目标：50+ 条参考文献。

## 原则

- 假设必须是机制性的（解释 WHY），不只是描述性的（说 WHAT）
- 竞争性假设必须可区分（不同预测）
- 始终引用文献支撑
