# 科研基金申请

## 概述

基金申请书是说服性文档，需要同时展示科学严谨性、创新性、可行性和广泛影响。不同机构有不同优先级的评审标准和格式。

## 核心原则

- **评审标准驱动写作**：每个机构明确其评审标准并逐条满足
- **显著性先行**：在技术细节前明确研究的重要性
- **可行性证据**：提供充分的初步数据和实施计划
- **广泛影响**：不仅说明科学价值，还说明社会价值

## 机构指南

### NSF（美国国家科学基金会）

| 要素 | 说明 |
|------|------|
| **评审标准** | Intellectual Merit + Broader Impacts（同等权重） |
| **篇幅** | 15 页 project description |
| **重点** | 教育、多样性、社会效益、开放数据 |
| **评审** | 专家小组 + 外部评审 |

### NIH（美国国立卫生研究院）

| 要素 | 说明 |
|------|------|
| **评审标准** | Significance, Investigator, Innovation, Approach, Environment |
| **格式** | Specific Aims（1 页）+ Research Strategy（12 页） |
| **重点** | 生物医学、临床转化 |
| **评审** | 研究部门评审 + 理事会 |

### DOE（美国能源部）

| 要素 | 说明 |
|------|------|
| **评审标准** | Scientific Merit, Relevance, Approach, Capability |
| **重点** | 能源、基础科学、国家安全 |
| **格式** | 因项目而异，通常 10-25 页 |

### DARPA（美国国防高级研究计划局）

| 要素 | 说明 |
|------|------|
| **评审标准** | Innovation, Impact, Feasibility, Team |
| **格式** | 通常无严格页数限制，但要求简洁 |
| **风格** | 高风险高回报、变革性技术 |
| **独特要求** | 通常需要里程碑驱动的执行计划 |

### NSTC（台湾国家科学及技术委员会）

| 要素 | 说明 |
|------|------|
| **语言** | 中文或英文 |
| **评审标准** | 学术价值、方法论、可行性、预期贡献 |
| **格式** | ~15-20 页 |

## 通用结构与写作

### 核心组成部分

1. **标题与摘要**（~250字）：研究目标、方法、创新点、影响
2. **具体目标 / Specific Aims**（1页）：清晰简洁的目标列表
3. **背景与意义**（2-3页）：研究缺口、为什么现在做、为什么你做
4. **创新性说明**（1页）：方法/概念上的创新点
5. **研究方案**（6-10页）：实验设计、方法、数据分析、预期结果
6. **初步数据**（1-2页）：已有成果支撑可行性
7. **广泛影响 / Broader Impacts**（1-2页）：教育、多样性、社会效益
8. **日程与里程碑**（0.5-1页）：甘特图或时间线
9. **预算依据**（1-2页）：人员、设备、差旅等

### 撰写策略

**显著性声明**：为什么这个研究重要？如果成功会改变什么？
- 用数据说明问题规模：影响多少人、造成多少损失
- 引用近期权威报告和支持

**创新性叙事**：你的方法/概念与现有工作有何不同？
- 清楚地说明"现状"与"你的方法"的对比
- 避免只说"尚未有人做过"，更要说明"为什么预计会有效"

**可行性论证**：为什么你能做成？
- 团队相关经验（引用已发表工作）
- 初步数据（最有力的可行性证据）
- 清晰的实施计划（备选方案）

**广泛影响声明**：
- 教育：培养本科生/研究生、开发课程、公开讲座
- 多样性：服务不足群体参与、包容性培训
- 社会效益：政策影响、公众科普、产业合作

### 常见问题

| 问题 | 解决 |
|------|------|
| 目标过于宽泛 | 聚焦 2-3 个具体、可检验的目标 |
| 不够具体 | 明确实验设计、预期结果、统计方法 |
| 缺乏初步数据 | 至少进行小规模验证或概念验证实验 |
| 创新性不突出 | 明确对比现有方法，清晰说明区别 |
| 可行性存疑 | 展示相关经验、资源和风险管理 |
| 影响不明确 | 量化预期产出和受益群体 |
